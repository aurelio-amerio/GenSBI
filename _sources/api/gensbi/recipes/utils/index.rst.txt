.. py:function:: _resolve_embedding_ids(dim, strategy, semantic_id)

   
   Resolve ID embeddings by strategy name.

   :param dim: Dimension specification (number of tokens, or (H, W) for 2D images).
   :type dim: int or tuple of int
   :param strategy: Embedding strategy name (e.g., "absolute", "pos1d", "rope1d",
                    "pos2d", "rope2d").
   :type strategy: str
   :param semantic_id: Semantic identifier for the token group (0=obs, 1=cond).
   :type semantic_id: int

   :returns: * **ids** (*Array*) -- Token ID array.
             * **resolved_dim** (*int*) -- Resolved flat dimension.

   :raises ValueError: If ``strategy`` is not recognized.

.. py:function:: build_edm_path(sde, config)

   
   Build an EDM-family diffusion path from an SDE type string and config.

   :param sde: SDE type: ``"EDM"``, ``"VE"``, or ``"VP"``.
   :type sde: str
   :param config: Training configuration dict; scheduler hyperparameters are read from
                  here with sensible defaults.
   :type config: dict

   :returns: Configured diffusion path.
   :rtype: EDMPath

   :raises ValueError: If ``sde`` is not one of ``{"EDM", "VE", "VP"}``.
