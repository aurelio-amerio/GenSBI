.. py:class:: JointDiffusionPipeline(model, train_dataset, val_dataset, dim_obs, dim_cond, ch_obs=1, params=None, training_config=None, condition_mask_kind='structured')

   Bases: :py:obj:`gensbi.recipes.pipeline.AbstractPipeline`


   
   Diffusion pipeline for training and using a Joint model for simulation-based inference.

   :param train_dataset: Training dataset.
   :type train_dataset: grain dataset or iterator over batches
   :param val_dataset: Validation dataset.
   :type val_dataset: grain dataset or iterator over batches
   :param dim_obs: Dimension of the parameter space.
   :type dim_obs: int
   :param dim_cond: Dimension of the observation space.
   :type dim_cond: int
   :param ch_obs: Number of channels for the observation space. Default is 1.
   :type ch_obs: int, optional
   :param params: Parameters for the Joint model. If None, default parameters are used.
   :type params: optional
   :param training_config: Configuration for training. If None, default configuration is used.
   :type training_config: dict, optional
   :param condition_mask_kind: Kind of condition mask to use. One of ["structured", "posterior"].
   :type condition_mask_kind: str, optional

   .. rubric:: Examples

   Minimal example on how to instantiate and use the JointDiffusionPipeline:

.. py:function:: sample_structured_conditional_mask(key, num_samples, theta_dim, x_dim, p_joint=0.2, p_posterior=0.2, p_likelihood=0.2, p_rnd1=0.2, p_rnd2=0.2, rnd1_prob=0.3, rnd2_prob=0.7)

   
   Sample structured conditional masks for the Joint model.

   :param key: Random key for sampling.
   :type key: jax.random.PRNGKey
   :param num_samples: Number of samples to generate.
   :type num_samples: int
   :param theta_dim: Dimension of the parameter space.
   :type theta_dim: int
   :param x_dim: Dimension of the observation space.
   :type x_dim: int
   :param p_joint: Probability of selecting the joint mask.
   :type p_joint: float
   :param p_posterior: Probability of selecting the posterior mask.
   :type p_posterior: float
   :param p_likelihood: Probability of selecting the likelihood mask.
   :type p_likelihood: float
   :param p_rnd1: Probability of selecting the first random mask.
   :type p_rnd1: float
   :param p_rnd2: Probability of selecting the second random mask.
   :type p_rnd2: float
   :param rnd1_prob: Probability of a True value in the first random mask.
   :type rnd1_prob: float
   :param rnd2_prob: Probability of a True value in the second random mask.
   :type rnd2_prob: float

   :returns: **condition_mask** -- Array of shape (num_samples, theta_dim + x_dim) with boolean masks.
   :rtype: jnp.ndarray
