.. py:class:: JointPipeline(model, train_dataset, val_dataset, dim_obs, dim_cond, method, ch_obs=1, condition_mask_kind='structured', params=None, training_config=None)

   Bases: :py:obj:`gensbi.recipes.pipeline.AbstractPipeline`


   
   Model-agnostic joint pipeline parameterized by a ``GenerativeMethod``.

   Unlike the old method-specific pipeline classes, this class works with
   **any** generative method and **any** user-provided model that conforms
   to the ``JointWrapper`` interface.

   :param model: The model to be trained.
   :type model: nnx.Module
   :param train_dataset: Training dataset yielding concatenated ``x_1`` batches
                         (obs and cond concatenated along the token dimension).
   :type train_dataset: iterable
   :param val_dataset: Validation dataset.
   :type val_dataset: iterable
   :param dim_obs: Dimension of the observation/parameter space.
   :type dim_obs: int
   :param dim_cond: Dimension of the conditioning space.
   :type dim_cond: int
   :param method: Strategy object (e.g. ``FlowMatchingMethod()``,
                  ``DiffusionEDMMethod()``, ``ScoreMatchingMethod()``).
   :type method: GenerativeMethod
   :param ch_obs: Number of channels per token. Default is 1.
   :type ch_obs: int, optional
   :param condition_mask_kind: Kind of condition mask. One of ``"structured"`` or ``"posterior"``.
                               Default is ``"structured"``.
   :type condition_mask_kind: str, optional
   :param params: Model parameters (stored but not used directly).
   :type params: optional
   :param training_config: Training configuration.
   :type training_config: dict, optional

   .. rubric:: Examples

   >>> from gensbi.core import FlowMatchingMethod
   >>> pipeline = JointPipeline(
   ...     model=my_model,
   ...     train_dataset=train_ds,
   ...     val_dataset=val_ds,
   ...     dim_obs=2, dim_cond=7,
   ...     method=FlowMatchingMethod(),
   ... )

   .. py:method:: get_log_prob_fn(x_o, use_ema=True, prior=None, model_extras=None, **kwargs)

      
      Get a log-probability function.

      :param x_o: Conditioning variable (observed data).
      :type x_o: array-like
      :param use_ema: Whether to use the EMA model. Default is True.
      :type use_ema: bool, optional
      :param prior: Obs-space prior for log-probability evaluation. The method's
                    prior lives on the full joint space ``(dim_joint, ch)`` and
                    cannot be automatically marginalized for arbitrary priors.

                    - **Default Gaussian**: auto-constructed — no need to provide.
                    - **Custom prior**: must supply the correct obs-space marginal.
      :type prior: numpyro.distributions.Distribution, optional
      :param model_extras: Additional model extras. Cannot override protected keys.
      :type model_extras: dict, optional
      :param \*\*kwargs: Forwarded to ``method.build_log_prob_fn``.

      :returns: ``log_prob_fn(x_1) -> log_prob``
      :rtype: Callable

      :raises ValueError: If the joint prior is non-Gaussian and no ``prior`` is provided.
