.. py:class:: ConditionalPipeline(model, train_dataset, val_dataset, dim_obs, dim_cond, method, ch_obs=1, ch_cond=1, id_embedding_strategy=('absolute', 'absolute'), params=None, training_config=None)

   Bases: :py:obj:`gensbi.recipes.pipeline.AbstractPipeline`


   
   Model-agnostic conditional pipeline parameterized by a ``GenerativeMethod``.

   Unlike the old method-specific pipeline classes, this class
   works with **any** generative method and **any** user-provided model that
   conforms to the ``ConditionalWrapper`` interface.

   :param model: The model to be trained.
   :type model: nnx.Module
   :param train_dataset: Training dataset yielding ``(obs, cond)`` batches.
   :type train_dataset: iterable
   :param val_dataset: Validation dataset yielding ``(obs, cond)`` batches.
   :type val_dataset: iterable
   :param dim_obs: Dimension of the observation/parameter space.
   :type dim_obs: int or tuple of int
   :param dim_cond: Dimension of the conditioning space.
   :type dim_cond: int or tuple of int
   :param method: Strategy object (e.g. ``FlowMatchingMethod()``,
                  ``DiffusionEDMMethod()``, ``ScoreMatchingMethod()``).
   :type method: GenerativeMethod
   :param ch_obs: Number of channels per observation token. Default is 1.
   :type ch_obs: int, optional
   :param ch_cond: Number of channels per conditioning token. Default is 1.
   :type ch_cond: int, optional
   :param id_embedding_strategy: Embedding strategy for observation and conditioning IDs.
                                 Default is ``("absolute", "absolute")``.
   :type id_embedding_strategy: tuple of str, optional
   :param params: Model parameters (stored but not used directly).
   :type params: optional
   :param training_config: Training configuration. If ``None``, uses defaults augmented
                           by ``method.get_extra_training_config()``.
   :type training_config: dict, optional

   .. rubric:: Examples

   >>> from gensbi.core import FlowMatchingMethod
   >>> pipeline = ConditionalPipeline(
   ...     model=my_model,
   ...     train_dataset=train_ds,
   ...     val_dataset=val_ds,
   ...     dim_obs=5, dim_cond=3,
   ...     method=FlowMatchingMethod(),
   ... )
