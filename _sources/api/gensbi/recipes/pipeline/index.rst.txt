gensbi.recipes.pipeline
=======================

.. py:module:: gensbi.recipes.pipeline

.. autoapi-nested-parse::

   Pipeline module for GenSBI.

   This module provides an abstract pipeline class for training and evaluating conditional generative models
   (such as conditional flow matching or diffusion models) in the GenSBI framework. It handles model creation,
   training loop, optimizer setup, checkpointing, and evaluation utilities.

   For practical implementations, subclasses should implement specific model architectures, loss functions, and sampling methods.
   See `JointPipeline` and `ConditionalPipeline` for concrete examples.

.. py:class:: AbstractPipeline(model, train_dataset, val_dataset, dim_obs, dim_cond, ch_obs=1, ch_cond=None, params=None, training_config=None)

   Bases: :py:obj:`abc.ABC`


   
   Abstract base class for GenSBI training pipelines.

   This class provides a template for implementing training and evaluation pipelines for conditional generative models.
   Subclasses should implement model creation, default parameter setup, loss function, sampling, and evaluation methods.

   :param train_dataset: Training dataset, should yield batches of data.
   :type train_dataset: iterable
   :param val_dataset: Validation dataset, should yield batches of data.
   :type val_dataset: iterable
   :param dim_obs: Dimensionality of the parameter (theta) space.
   :type dim_obs: int
   :param dim_cond: Dimensionality of the observation (x) space.
   :type dim_cond: int
   :param model: The model to be trained. If None, the model is created using `_make_model`.
   :type model: nnx.Module, optional
   :param params: Model parameters. If None, uses defaults from `_get_default_params`.
   :type params: dict, optional
   :param ch_obs: Number of channels in the observation data. Default is 1.
   :type ch_obs: int, optional
   :param ch_cond: Number of channels in the conditional data (if applicable). Default is None.
   :type ch_cond: int, optional
   :param training_config: Training configuration. If None, uses defaults from `get_default_training_config`.
   :type training_config: dict, optional

.. py:class:: ModelEMA(model, tx)

   Bases: :py:obj:`flax.nnx.Optimizer`


   
   Exponential Moving Average (EMA) optimizer for maintaining a smoothed version of model parameters.

   This optimizer keeps an exponential moving average of the model parameters, which can help stabilize training
   and improve evaluation performance. The EMA parameters are updated at each training step.

   :param model: The model whose parameters will be tracked.
   :type model: nnx.Module
   :param tx: The Optax transformation defining the EMA update rule.
   :type tx: optax.GradientTransformation
