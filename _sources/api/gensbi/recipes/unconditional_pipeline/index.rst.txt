   .. py:method:: get_sampler(nsteps=18, use_ema=True, return_intermediates=False, solver=None, **model_extras)

      
      Get a sampler function for the diffusion model.

      :param nsteps: Number of sampling steps. Default is 18.
      :type nsteps: int, optional
      :param use_ema: Whether to use the EMA model. Default is True.
      :type use_ema: bool, optional
      :param return_intermediates: Whether to return intermediate steps. Default is False.
      :type return_intermediates: bool, optional
      :param solver: A tuple ``(SolverClass, solver_kwargs)`` specifying the solver
                     class and its constructor keyword arguments.
                     Defaults to ``(EDMSolver, {})``.

                     The solver class must accept ``score_model`` and ``path`` as
                     its first two positional arguments.

                     EDM-specific options can be provided in the kwargs dict:

                     - ``solver_scheduler``: override the path's scheduler for
                       sampling (also used for ``sample_prior``).
                     - ``solver_params``: dict of EDM solver parameters
                       (``S_churn``, ``S_min``, ``S_max``, ``S_noise``).
      :type solver: tuple of (type, dict), optional
      :param \*\*model_extras: Additional keyword arguments passed to the model.
      :type \*\*model_extras: dict

      :returns: A function ``sampler(key, nsamples)`` that generates samples.
      :rtype: Callable

      .. rubric:: Examples

      Using the default EDM solver:

      >>> sampler = pipeline.get_sampler()
      >>> samples = sampler(key, nsamples=1000)

      Using a custom scheduler:

      >>> from gensbi.diffusion.solver import EDMSolver
      >>> from gensbi.diffusion.path.scheduler import VEEdmScheduler
      >>> solver = (EDMSolver, {"solver_scheduler": VEEdmScheduler()})
      >>> sampler = pipeline.get_sampler(solver=solver)
      >>> samples = sampler(key, nsamples=1000)

   .. py:method:: sample(key, nsamples=10000, nsteps=18, use_ema=True, return_intermediates=False, solver=None, **model_extras)

      
      Draw samples from the diffusion model.

      Convenience method that internally calls :meth:`get_sampler` and
      immediately evaluates the returned sampler function.

      :param key: JAX random key used for sampling.
      :type key: jax.random.PRNGKey
      :param nsamples: Number of samples to draw. Default is 10 000.
      :type nsamples: int, optional
      :param nsteps: Number of sampling steps. Default is 18.
      :type nsteps: int, optional
      :param use_ema: Whether to use the EMA model. Default is True.
      :type use_ema: bool, optional
      :param return_intermediates: Whether to return intermediate steps. Default is False.
      :type return_intermediates: bool, optional
      :param solver: A tuple ``(SolverClass, solver_kwargs)`` specifying the solver
                     class and its keyword arguments. Defaults to ``(EDMSolver, {})``.

                     EDM-specific options can be provided in the kwargs dict:

                     - ``solver_scheduler``: override the path's scheduler for
                       sampling (also used for ``sample_prior``).
                     - ``solver_params``: dict of EDM solver parameters
                       (``S_churn``, ``S_min``, ``S_max``, ``S_noise``).
      :type solver: tuple of (type, dict), optional
      :param \*\*model_extras: Additional keyword arguments passed to the model.
      :type \*\*model_extras: dict

      :returns: Sampled output of shape ``(nsamples, dim_obs, ch_obs)``.
      :rtype: Array

      .. rubric:: Examples

      Using the default EDM solver:

      >>> samples = pipeline.sample(key, nsamples=1000)

      Using a custom scheduler:

      >>> from gensbi.diffusion.solver import EDMSolver
      >>> from gensbi.diffusion.path.scheduler import VEEdmScheduler
      >>> solver = (EDMSolver, {"solver_scheduler": VEEdmScheduler()})
      >>> samples = pipeline.sample(key, solver=solver)

   .. py:method:: get_sampler(step_size=0.01, use_ema=True, time_grid=None, solver=None, **model_extras)

      
      Get a sampler function for the flow model.

      :param step_size: Step size for the solver. Default is 0.01.
      :type step_size: float, optional
      :param use_ema: Whether to use the EMA model. Default is True.
      :type use_ema: bool, optional
      :param time_grid: Time grid for intermediate steps. If None, uses ``[0, 1]``.
      :type time_grid: Array, optional
      :param solver: A tuple ``(SolverClass, solver_kwargs)`` specifying the solver
                     class and its constructor keyword arguments.
                     Defaults to ``(ODESolver, {})``.

                     For SDE solvers (e.g., ``ZeroEnds``, ``NonSingular``), additional
                     constructor arguments must be provided via the kwargs dict.
                     A random key is automatically passed to SDE samplers.
      :type solver: tuple of (type, dict), optional
      :param \*\*model_extras: Additional keyword arguments passed to the model.
      :type \*\*model_extras: dict

      :returns: A function ``sampler(key, nsamples)`` that generates samples.
      :rtype: Callable

      .. rubric:: Examples

      Using the default ODE solver:

      >>> sampler = pipeline.get_sampler()
      >>> samples = sampler(key, nsamples=1000)

      Using the ZeroEnds SDE solver:

      >>> import jax.numpy as jnp
      >>> from gensbi.flow_matching.solver import ZeroEnds
      >>> solver = (ZeroEnds, {
      ...     "mu0": jnp.zeros((dim_obs, ch_obs)),
      ...     "sigma0": jnp.ones((dim_obs, ch_obs)),
      ...     "alpha": 1.0,
      ... })
      >>> sampler = pipeline.get_sampler(solver=solver)
      >>> samples = sampler(key, nsamples=1000)

.. py:class:: UnconditionalSMPipeline(model, train_dataset, val_dataset, dim_obs, ch_obs = 1, sde_type = 'VP', params=None, training_config=None)

   Bases: :py:obj:`gensbi.recipes.pipeline.AbstractPipeline`


   
   Score matching pipeline for training and using an Unconditional model for simulation-based inference.

   Supports both Variance Preserving (VP) and Variance Exploding (VE) SDE formulations.

   :param model: The model to be trained.
   :type model: nnx.Module
   :param train_dataset: Training dataset.
   :type train_dataset: grain dataset or iterator over batches
   :param val_dataset: Validation dataset.
   :type val_dataset: grain dataset or iterator over batches
   :param dim_obs: Dimension of the parameter space.
   :type dim_obs: int
   :param ch_obs: Number of channels in the observation space.
   :type ch_obs: int
   :param sde_type: Type of SDE to use. One of ``"VP"`` (Variance Preserving) or ``"VE"`` (Variance Exploding).
   :type sde_type: str
   :param params: Parameters for the model. Serves no use if a custom model is provided.
   :type params: optional
   :param training_config: Configuration for training. If None, default configuration is used.
   :type training_config: dict, optional

      Get a sampler function for the score matching model.

      :param nsteps: Number of integration steps. Default is 1000.
      :type nsteps: int, optional
      :param use_ema: Whether to use the EMA model. Default is True.
      :type use_ema: bool, optional
      :param return_intermediates: Whether to return intermediate steps. Default is False.
      :type return_intermediates: bool, optional
      :param solver: A tuple ``(SolverClass, solver_kwargs)`` specifying the solver
                     class and its constructor keyword arguments.
                     Defaults to ``(SMSolver, {})``.
