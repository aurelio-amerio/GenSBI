.. py:class:: UnconditionalPipeline(model, train_dataset, val_dataset, dim_obs, method, ch_obs=1, params=None, training_config=None)

   Bases: :py:obj:`gensbi.recipes.pipeline.AbstractPipeline`


   
   Model-agnostic unconditional pipeline parameterized by a ``GenerativeMethod``.

   Unlike the old method-specific pipeline classes, this
   class works with **any** generative method and **any** user-provided
   model that conforms to the ``UnconditionalWrapper`` interface.

   :param model: The model to be trained.
   :type model: nnx.Module
   :param train_dataset: Training dataset yielding ``x_1`` batches (not tuples).
   :type train_dataset: iterable
   :param val_dataset: Validation dataset.
   :type val_dataset: iterable
   :param dim_obs: Dimension of the data space.
   :type dim_obs: int
   :param method: Strategy object (e.g. ``FlowMatchingMethod()``,
                  ``DiffusionEDMMethod()``, ``ScoreMatchingMethod()``).
   :type method: GenerativeMethod
   :param ch_obs: Number of channels per token. Default is 1.
   :type ch_obs: int, optional
   :param params: Model parameters (stored but not used directly).
   :type params: optional
   :param training_config: Training configuration.
   :type training_config: dict, optional

   .. rubric:: Examples

   >>> from gensbi.core import FlowMatchingMethod
   >>> pipeline = UnconditionalPipeline(
   ...     model=my_model,
   ...     train_dataset=train_ds,
   ...     val_dataset=val_ds,
   ...     dim_obs=9,
   ...     method=FlowMatchingMethod(),
   ... )

   .. py:method:: sample_batched(*args, **kwargs)
      :abstractmethod:


      
      Generate samples from the trained model in batches.

      Loops over the ``B`` conditions in ``x_o`` one at a time and, when
      ``chunk_size`` is set, additionally draws each condition's samples
      in memory-bounded chunks of at most ``chunk_size`` samples per
      device call.

      :param key: Random number generator key.
      :type key: jax.random.PRNGKey
      :param x_o: Conditioning variable (e.g., observed data), leading batch
                  axis of size ``B``.
      :type x_o: array-like
      :param nsamples: Number of samples to generate per condition.
      :type nsamples: int
      :param chunk_size: Maximum number of samples drawn per device call. ``None``
                         (default) draws all ``nsamples`` for a condition in a single
                         call — identical to the historical behavior.
      :type chunk_size: int, optional
      :param show_progress_bars: Whether to display a progress bar over the
                                 ``B * n_chunks`` device calls. Default is True.
      :type show_progress_bars: bool, optional
      :param args: Additional positional arguments for the sampler.
      :type args: tuple
      :param kwargs: Additional keyword arguments for the sampler.
      :type kwargs: dict

      :returns: **samples** -- Generated samples of shape (nsamples, batch_size_cond, dim_obs, ch_obs).
      :rtype: array-like
