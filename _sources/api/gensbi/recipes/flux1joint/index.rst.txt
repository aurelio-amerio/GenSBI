   Diffusion pipeline for training and using a Joint model for simulation-based inference.

   :param train_dataset: Training dataset.
   :type train_dataset: grain dataset or iterator over batches
   :param val_dataset: Validation dataset.
   :type val_dataset: grain dataset or iterator over batches
   :param dim_obs: Dimension of the parameter space.
   :type dim_obs: int
   :param dim_cond: Dimension of the observation space.
   :type dim_cond: int
   :param ch_obs: Number of channels for the observation space. Default is 1.
   :type ch_obs: int, optional
   :param params: Parameters for the Joint model. If None, default parameters are used.
   :type params: optional
   :param training_config: Configuration for training. If None, default configuration is used.
   :type training_config: dict, optional
   :param condition_mask_kind: Kind of condition mask to use. One of ["structured", "posterior"].
   :type condition_mask_kind: str, optional

.. py:class:: Flux1JointSMPipeline(train_dataset, val_dataset, dim_obs, dim_cond, ch_obs = 1, sde_type = 'VP', params=None, training_config=None, condition_mask_kind='structured')

   Bases: :py:obj:`gensbi.recipes.joint_pipeline.JointSMPipeline`


   
   Score matching pipeline for training and using a Joint model for simulation-based inference.

   Supports both Variance Preserving (VP) and Variance Exploding (VE) SDE formulations.

   :param model: The model to be trained.
   :type model: nnx.Module
   :param train_dataset: Training dataset.
   :type train_dataset: grain dataset or iterator over batches
   :param val_dataset: Validation dataset.
   :type val_dataset: grain dataset or iterator over batches
   :param dim_obs: Dimension of the parameter space.
   :type dim_obs: int
   :param dim_cond: Dimension of the observation space.
   :type dim_cond: int
   :param ch_obs: Number of channels for the observation space. Default is 1.
   :type ch_obs: int, optional
   :param sde_type: Type of SDE to use. One of ``"VP"`` (Variance Preserving) or ``"VE"`` (Variance Exploding).
   :type sde_type: str
   :param params: Parameters for the Joint model. If None, default parameters are used.
   :type params: optional
   :param training_config: Configuration for training. If None, default configuration is used.
   :type training_config: dict, optional
   :param condition_mask_kind: Kind of condition mask to use. One of ["structured", "posterior"].
   :type condition_mask_kind: str, optional
