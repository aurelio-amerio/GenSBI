gensbi.diffusion.loss
=====================

.. py:module:: gensbi.diffusion.loss

.. autoapi-nested-parse::

   
   Diffusion loss functions with unified interface.

   This subpackage provides :class:`EDMLoss` and :class:`SMLoss`, which wrap
   the path-specific loss functions into a uniform
   ``(model, batch, condition_mask, model_extras)`` interface.

.. py:class:: EDMLoss(path, weights=None)

   
   EDM denoising loss with a uniform ``(model, batch, ...)`` interface.

   Wraps ``EDMPath.get_loss_fn()`` so that the calling convention matches
   :class:`~gensbi.flow_matching.loss.FMLoss` and
   :class:`~gensbi.diffusion.loss.SMLoss`.

   :param path: The diffusion path.
   :type path: EDMPath
   :param weights: Weights for the loss, applied element-wise before reduction.
   :type weights: Array, optional
