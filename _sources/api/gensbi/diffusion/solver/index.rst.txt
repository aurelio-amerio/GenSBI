gensbi.diffusion.solver
=======================

.. py:module:: gensbi.diffusion.solver

.. autoapi-nested-parse::

   
   Solvers for generative diffusion models.

   This module provides SDE solvers specifically designed for sampling from generative
   diffusion models, including stochastic differential equation integration methods
   as detailed in the EDM paper "Elucidating the Design Space of Diffusion-Based
   Generative Models" (Karras et al., 2022) and standard score matching samplers
   from "Score-Based Generative Modeling through Stochastic Differential Equations"
   (Song et al., 2021).

.. py:class:: SMPFSolver(score_model, path)

   Bases: :py:obj:`SMSolver`


   
   Solver for score matching diffusion models using the Probability Flow ODE.

   Instead of the reverse SDE, this solver integrates the deterministic
   Probability Flow ODE (PF-ODE) from section 4.3 of Song et al., 2021
   (arXiv:2011.13456). The PF-ODE shares the same marginal distributions
   as the reverse SDE but is fully deterministic, which often leads to
   higher sample quality and enables exact likelihood computation.

   The PF-ODE is:

   .. math::
       dx = \left[ f(x,t) - \frac{1}{2} g(t)^2 s_\theta(x, t) \right] dt

   :param score_model: The score model function.
   :type score_model: Callable
   :param path: The SMPath object containing the SDE scheduler.
   :type path: SMPath

   .. rubric:: Example

   .. code-block:: python

       from gensbi.diffusion.solver.sm_solver import SMPFSolver
       from gensbi.diffusion.path.sm_path import SMPath
       from gensbi.diffusion.path.scheduler.sm_sde import VPSmScheduler
       import jax, jax.numpy as jnp
       sde = VPSmScheduler()
       path = SMPath(sde)
       def score_model(obs, t, **kwargs):
           return jnp.zeros_like(obs)
       solver = SMPFSolver(score_model, path)
       key = jax.random.PRNGKey(0)
       x_init = jax.random.normal(key, (16, 2, 1))
       samples = solver.sample(key, x_init, nsteps=10)
       print(samples.shape)
       # (16, 2, 1)

.. py:class:: SMSolver(score_model, path)

   Bases: :py:obj:`gensbi.solver.Solver`


   
   Solver for standard score matching diffusion models.

   Uses reverse SDE sampling via Euler-Maruyama integration.

   :param score_model: The score model function.
   :type score_model: Callable
   :param path: The SMPath object containing the SDE scheduler.
   :type path: SMPath

   .. rubric:: Example

   .. code-block:: python

       from gensbi.diffusion.solver.sm_solver import SMSolver
       from gensbi.diffusion.path.sm_path import SMPath
       from gensbi.diffusion.path.scheduler.sm_sde import VPSmScheduler
       import jax, jax.numpy as jnp
       sde = VPSmScheduler()
       path = SMPath(sde)
       def score_model(obs, t, **kwargs):
           return jnp.zeros_like(obs)
       solver = SMSolver(score_model, path)
       key = jax.random.PRNGKey(0)
       x_init = jax.random.normal(key, (16, 2))
       samples = solver.sample(key, x_init, nsteps=10)
       print(samples.shape)
       # (16, 2)
