gensbi.diffusion.path
=====================

.. py:module:: gensbi.diffusion.path

.. autoapi-nested-parse::

   
   Probability paths for diffusion models.

   This module provides probability path implementations for diffusion models,
   including the EDM path from the paper "Elucidating the Design Space of
   Diffusion-Based Generative Models" (Karras et al., 2022) and the standard
   score matching path from "Score-Based Generative Modeling through Stochastic
   Differential Equations" (Song et al., 2021).

.. py:class:: EDMPath(scheduler)

   Bases: :py:obj:`gensbi.diffusion.path.path.ProbPath`


   
   EDM probability path.

   This class implements the probability path for EDM-based diffusion models,
   supporting different noise schedules (EDM, EDM-VP, EDM-VE).

   :param scheduler:
   :type scheduler: The scheduler object for noise generation, must be one of 'EDM', 'EDM-VP', or 'EDM-VE'.

   .. rubric:: Example

   .. code-block:: python

       from gensbi.diffusion.path import EDMPath
       from gensbi.diffusion.path.scheduler import EDMScheduler
       import jax, jax.numpy as jnp
       scheduler = EDMScheduler()
       path = EDMPath(scheduler)
       key = jax.random.PRNGKey(0)
       x_1 = jax.random.normal(key, (32, 2))
       sigma = jnp.ones((32, 1))
       sample = path.sample(key, x_1, sigma)
       print(sample.x_t.shape)
       # (32, 2)

.. py:class:: SMPath(scheduler)

   Bases: :py:obj:`gensbi.diffusion.path.path.ProbPath`


   
   Score Matching probability path.

   This class constructs noised samples for standard score matching training
   using the forward SDE's marginal distributions.

   The noising is: x_t = mean_coeff(t) * x_1 + std(t) * epsilon

   :param scheduler:
   :type scheduler: The SDE scheduler object (VPSmScheduler or VESmScheduler).

   .. rubric:: Example

   .. code-block:: python

       from gensbi.diffusion.path.sm_path import SMPath
       from gensbi.diffusion.path.scheduler.sm_sde import VPSmScheduler
       import jax, jax.numpy as jnp
       scheduler = VPSmScheduler()
       path = SMPath(scheduler)
       key = jax.random.PRNGKey(0)
       x_1 = jax.random.normal(key, (32, 2))
       sample = path.sample(key, x_1)
       print(sample.x_t.shape)
       # (32, 2)

   .. py:method:: get_loss_fn()

      
      Returns the loss function for score matching training.

      The loss is the denoising score matching objective:

      .. math::
          g(t)^2 \left\| s_\theta(x_t, t) - \left(-\frac{\epsilon}{\sigma(t)}\right) \right\|^2

      where :math:`-\epsilon / \sigma(t)` is the true score :math:`\nabla_x \log p(x_t | x_0)`.

      :returns: Loss function.
      :rtype: Callable
