.. py:class:: MCLMC(*, adjusted=True, num_samples=1000, num_tuning_steps=5000, num_chains=1, target_acceptance=0.9, diagonal_preconditioning=True)

   Bases: :py:obj:`Sampler`


   
   Microcanonical Langevin Monte Carlo sampler.

   ``adjusted=True`` (the default) applies an MH correction for
   asymptotically exact sampling.  ``adjusted=False`` uses the faster
   unadjusted variant, which is biased by the discretization error.

   :param adjusted: Whether to apply an MH correction.  Default is ``True``.
   :type adjusted: bool, optional
   :param num_samples: Number of posterior samples to collect per chain.  Default is 1000.
   :type num_samples: int, optional
   :param num_tuning_steps: Number of warmup steps for the L / step-size tuning loop.
                            Default is 5000.
   :type num_tuning_steps: int, optional
   :param num_chains: Number of independent MCLMC chains.  Default is 1.
   :type num_chains: int, optional
   :param target_acceptance: Target Metropolis acceptance rate for the adjusted variant.
                             Default is 0.9.
   :type target_acceptance: float, optional
   :param diagonal_preconditioning: Whether to use diagonal preconditioning during tuning.
                                    Default is ``True``.
   :type diagonal_preconditioning: bool, optional

.. py:class:: NestedSampler(*, num_live=500, num_delete=None, num_inner_steps=None, num_samples=1000, dlogz=-3.0, max_iterations=100000, num_rejuvenation_steps=0)

   Bases: :py:obj:`Sampler`


   
   Nested slice sampling (blackjax ``nss``) posterior sampler.

   Runs blackjax's Nested Slice Sampling from prior-drawn live points,
   accumulating dead points until the live set's evidence share is
   negligible, then resamples the dead-point history into equal-weight
   posterior draws.  Unlike the MCMC samplers this also estimates the
   log evidence, and handles multimodal posteriors without tempering.

   :param num_live: Number of live points.  Default is 500.
   :type num_live: int, optional
   :param num_delete: Number of lowest-likelihood points replaced per step (device
                      batching).  If ``None``, defaults to ``max(1, num_live // 10)``.
   :type num_delete: int or None, optional
   :param num_inner_steps: Constrained slice moves per replacement.  If ``None``, resolved
                           at run time to ``max(5, 2 * target.dim)`` (blackjax's rule of
                           thumb for reliable mixing).  Default is ``None``.
   :type num_inner_steps: int or None, optional
   :param num_samples: Number of equal-weight posterior draws returned.  Default is 1000.
   :type num_samples: int, optional
   :param dlogz: Termination threshold (blackjax convention): stop once
                 ``logZ_live - logZ < dlogz``.  Default is -3.0; use e.g. -10.0
                 near phase transitions.
   :type dlogz: float, optional
   :param max_iterations: Safety cap on the number of outer NS steps.  Default is 100_000.
   :type max_iterations: int, optional
   :param num_rejuvenation_steps: Posterior-invariant hit-and-run slice moves applied to each
                                  equal-weight draw after resampling.  The with-replacement resampling
                                  duplicates draws whenever ``num_samples`` is comparable to the run's
                                  ESS; a few slice moves break the duplicated atoms without changing
                                  the sampled distribution.  Default is 0 (no rejuvenation).
   :type num_rejuvenation_steps: int, optional

   .. py:method:: _rejuvenate(key, positions, target)

      
      Break duplicated equal-weight draws with posterior-invariant moves.

      Runs ``num_rejuvenation_steps`` hit-and-run slice moves on every
      resampled draw (one vmapped chain per draw), targeting the
      unconstrained log-posterior.  Directions are shaped by the empirical
      covariance of the resampled cloud and scaled to Mahalanobis norm 2,
      the same proposal the NS run's inner kernel uses -- so the moves are
      local decorrelation only; mode coverage and weights stay as the NS
      run left them.

.. py:class:: TemperedSMC(*, num_particles=1000, target_ess=0.9, num_mcmc_steps=10, inner_kernel='mclmc', inner_step_size=0.1, inner_num_integration_steps=5, inner_inverse_mass_matrix=None)

   Bases: :py:obj:`Sampler`


   
   Adaptive tempered Sequential Monte Carlo for (possibly multimodal) posteriors.

   Walks particles along ``p(theta) * q(x_o | theta)^beta`` for beta from 0
   to 1, choosing the beta ladder adaptively to maintain ``target_ess``.  The
   inner rejuvenation kernel is adjusted MCLMC by default; fixed-trajectory
   HMC is available as an alternative. (NUTS is deliberately not offered: its
   data-dependent trajectory length does not vectorize cleanly across SMC
   particles, and rejuvenation does not need NUTS's full-mixing guarantee.)

   ``target_ess`` and ``num_mcmc_steps`` default to values calibrated for
   blackjax >= 1.6, whose adaptive-tempering ESS solver was corrected
   (upstream #914 fixed a sign bug in the bisection target). The fix
   changes how many temperature steps are needed to anneal from beta=0 to
   1: with the pre-1.6-era ``target_ess=0.5`` default, the corrected
   solver can collapse the schedule to a single step, leaving too few
   temperature increments for rejuvenation to move particles onto the
   posterior.

   :param num_particles: Number of SMC particles.  Default is 1000.
   :type num_particles: int, optional
   :param target_ess: Target effective sample size ratio in ``(0, 1)``, used to adapt the
                      temperature increments.  Default is 0.9.
   :type target_ess: float, optional
   :param num_mcmc_steps: Number of inner MCMC rejuvenation steps per temperature.  Default is 10.
   :type num_mcmc_steps: int, optional
   :param inner_kernel: Inner MCMC kernel: ``"mclmc"`` (adjusted MCLMC, default) or
                        ``"hmc"`` (fixed-trajectory HMC).
   :type inner_kernel: str, optional
   :param inner_step_size: Step size for the inner MCMC kernel.  Default is 0.1.
   :type inner_step_size: float, optional
   :param inner_num_integration_steps: Number of integration steps for the inner MCLMC or HMC kernel.
                                       Default is 5.
   :type inner_num_integration_steps: int, optional
   :param inner_inverse_mass_matrix: Inverse mass matrix for the inner kernel.  If ``None``, defaults to a
                                     vector of ones of length ``target.dim``.  Default is ``None``.
   :type inner_inverse_mass_matrix: Array or None, optional
