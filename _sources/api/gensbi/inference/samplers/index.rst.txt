.. py:class:: MCLMC(*, adjusted=True, num_samples=1000, num_tuning_steps=5000, num_chains=1, target_acceptance=0.9, diagonal_preconditioning=True)

   Bases: :py:obj:`Sampler`


   
   Microcanonical Langevin Monte Carlo sampler.

   ``adjusted=True`` (the default) applies an MH correction for
   asymptotically exact sampling.  ``adjusted=False`` uses the faster
   unadjusted variant, which is biased by the discretization error.

   :param adjusted: Whether to apply an MH correction.  Default is ``True``.
   :type adjusted: bool, optional
   :param num_samples: Number of posterior samples to collect per chain.  Default is 1000.
   :type num_samples: int, optional
   :param num_tuning_steps: Number of warmup steps for the L / step-size tuning loop.
                            Default is 5000.
   :type num_tuning_steps: int, optional
   :param num_chains: Number of independent MCLMC chains.  Default is 1.
   :type num_chains: int, optional
   :param target_acceptance: Target Metropolis acceptance rate for the adjusted variant.
                             Default is 0.9.
   :type target_acceptance: float, optional
   :param diagonal_preconditioning: Whether to use diagonal preconditioning during tuning.
                                    Default is ``True``.
   :type diagonal_preconditioning: bool, optional

.. py:class:: TemperedSMC(*, num_particles=1000, target_ess=0.5, num_mcmc_steps=10, inner_kernel='mclmc', inner_step_size=0.1, inner_num_integration_steps=5, inner_inverse_mass_matrix=None)

   Bases: :py:obj:`Sampler`


   
   Adaptive tempered Sequential Monte Carlo for (possibly multimodal) posteriors.

   Walks particles along ``p(theta) * q(x_o | theta)^beta`` for beta from 0
   to 1, choosing the beta ladder adaptively to maintain ``target_ess``.  The
   inner rejuvenation kernel is adjusted MCLMC by default; NUTS is available
   as a fallback.

   :param num_particles: Number of SMC particles.  Default is 1000.
   :type num_particles: int, optional
   :param target_ess: Target effective sample size ratio in ``(0, 1)``, used to adapt the
                      temperature increments.  Default is 0.5.
   :type target_ess: float, optional
   :param num_mcmc_steps: Number of inner MCMC rejuvenation steps per temperature.  Default is 10.
   :type num_mcmc_steps: int, optional
   :param inner_kernel: Inner MCMC kernel: ``"mclmc"`` (adjusted MCLMC, default) or
                        ``"nuts"``.
   :type inner_kernel: str, optional
   :param inner_step_size: Step size for the inner MCMC kernel.  Default is 0.1.
   :type inner_step_size: float, optional
   :param inner_num_integration_steps: Number of integration steps for the inner MCLMC kernel.  Default is 5.
   :type inner_num_integration_steps: int, optional
   :param inner_inverse_mass_matrix: Inverse mass matrix for the inner kernel.  If ``None``, defaults to a
                                     vector of ones of length ``target.dim``.  Default is ``None``.
   :type inner_inverse_mass_matrix: Array or None, optional

.. py:function:: _check_rescale_domain(mu)

   
   Raise if the tuned ``mu = L / step_size`` is outside ``_rescale``'s domain.

   For ``mu < 1``, ``floor(2 * mu - 1) == 0`` and ``_rescale`` returns 0, so
   the integration-step draw ``ceil(U(0,1) * 0)`` is 0 — a chain that never
   moves. A host-side check on the tuned value turns that silent failure into
   an explicit error. (The in-tuning average is left to blackjax; this is a
   convenience sampler, not a fully hardened MCMC engine.)

.. py:function:: _rescale(mu)

   
   Map a mean trajectory length to a uniform-integer draw scale.

   From blackjax's ``adjusted_mclmc_dynamic``: drawing the number of
   integration steps as ``ceil(U(0,1) * _rescale(L/step_size))`` makes the
   average number of steps exactly ``mu = L / step_size``.

   ``mu`` must satisfy ``mu >= 1``; see :func:`_check_rescale_domain` for the
   host-side guard applied to the tuned value.
