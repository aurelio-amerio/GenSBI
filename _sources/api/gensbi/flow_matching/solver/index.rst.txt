.. py:class:: FMODESolver(velocity_model)

   Bases: :py:obj:`gensbi.core.ode_solver.ODESolver`


   
   Flow matching ODE solver.

   The drift for the ODE is the velocity field itself:

   .. math::
       dx = u_t(x)\, dt

   :param velocity_model: Wrapped velocity field model.
   :type velocity_model: ModelWrapper

   .. rubric:: Example

   .. code-block:: python

       from gensbi.flow_matching.solver.fm_ode_solver import FMODESolver
       from gensbi.utils.model_wrapping import ModelWrapper
       import jax.numpy as jnp

       model_wrapped = ModelWrapper(my_velocity_model)
       solver = FMODESolver(velocity_model=model_wrapped)
       sol = solver.sample(x_init, step_size=0.01, time_grid=jnp.array([0.0, 1.0]))

.. py:class:: FMSDESolver(velocity_model, mu0, sigma0, eps0 = 1e-05)

   Bases: :py:obj:`gensbi.core.sde_solver.SDESolver`


   
   Base flow matching SDE solver.

   Provides :meth:`get_score` which derives the score from the velocity
   field (see arXiv:2410.02217).  Subclasses implement :meth:`get_drift`
   (:math:`\tilde{f}`) and :meth:`get_diffusion` (:math:`\tilde{g}`) using the score and velocity field.

   :param velocity_model: Wrapped velocity field model.
   :type velocity_model: ModelWrapper
   :param mu0: Prior mean, shape ``(features, channels)``.
   :type mu0: Array
   :param sigma0: Prior std, shape ``(features, channels)``.
   :type sigma0: Array
   :param eps0: Minimum time value.
   :type eps0: float

.. py:class:: NonSingularSolver(velocity_model, mu0, sigma0, alpha)

   Bases: :py:obj:`FMSDESolver`


   
   NonSingular SDE solver for flow matching.

   From Tab. 1 of `arXiv:2410.02217 <http://arxiv.org/abs/2410.02217>`_,
   with change of variable for time: t → 1−t to match flow matching
   time notation.

   The drift (:math:`\tilde{f}`) and diffusion (:math:`\tilde{g}`) are:

   .. math::
       \tilde{f}(t, x) = u_t(x) + \tfrac{1}{2}\alpha^2 (1-t)\, s(t, x)

       \tilde{g}(t) = \alpha \sqrt{1-t}

   :param velocity_model: Velocity field model.
   :type velocity_model: ModelWrapper
   :param mu0: Prior mean, shape ``(features, channels)``.
   :type mu0: Array
   :param sigma0: Prior std, shape ``(features, channels)``.
   :type sigma0: Array
   :param alpha: Diffusion strength parameter.
   :type alpha: float

.. py:class:: ZeroEndsSolver(velocity_model, mu0, sigma0, alpha, eps0 = 0.001)

   Bases: :py:obj:`FMSDESolver`


   
   ZeroEnds SDE solver for flow matching.

   From Tab. 1 of `arXiv:2410.02217 <http://arxiv.org/abs/2410.02217>`_,
   with change of variable for time: t → 1−t to match flow matching
   time notation.

   The drift (:math:`\tilde{f}`) and diffusion (:math:`\tilde{g}`) are:

   .. math::
       \tilde{f}(t, x) = u_t(x) + \tfrac{1}{2}\alpha^2 t(1-t)\, s(t, x)

       \tilde{g}(t) = \alpha \sqrt{t(1-t)}

   :param velocity_model: Velocity field model.
   :type velocity_model: ModelWrapper
   :param mu0: Prior mean, shape ``(features, channels)``.
   :type mu0: Array
   :param sigma0: Prior std, shape ``(features, channels)``.
   :type sigma0: Array
   :param alpha: Diffusion strength parameter.
   :type alpha: float
   :param eps0: Minimum time value.
