.. py:class:: Affine(clamp_min = -5.0, clamp_max = 3.0)

   
   Elementwise affine transform with log-scale clamping.

   The parameter layout per dimension is ``[shift mu, log-scale a]``
   (``num_params == 2``).  Log-scale values are clamped to
   ``[clamp_min, clamp_max]`` before exponentiation using a straight-through
   gradient (NumPyro IAF trick).

   Forward (noise→data): ``x = u * exp(a) + mu``; logabsdet = ``+sum(a)``.
   Inverse (data→noise): ``u = (x - mu) * exp(-a)``; logabsdet = ``-sum(a)``.

   :param clamp_min: Lower bound for log-scale clamping.  Default is -5.0.
   :type clamp_min: float, optional
   :param clamp_max: Upper bound for log-scale clamping.  Default is 3.0.
   :type clamp_max: float, optional

.. py:class:: Bijection

   Bases: :py:obj:`flax.nnx.Module`


   
   Invertible map between a noise variable and a data variable.

   Subclasses implement a differentiable bijection with a direction
   convention fixed across the library: :meth:`forward` maps noise to data
   (the sampling direction) and :meth:`inverse` maps data to noise (the
   density-evaluation direction). Both directions also return the log
   absolute determinant of the Jacobian of the transform they apply.

.. py:class:: Chain(bijections)

   Bases: :py:obj:`gensbi.normalizing_flows.bijections.base.Bijection`


   
   Sequential composition of bijections.

   Applies bijections in the order given for :meth:`forward` (noise→data)
   and in reversed order for :meth:`inverse` (data→noise).  Log-absolute
   determinants accumulate by summation.  ``bijections[-1]`` is closest to
   data space; it is the last bijection applied in :meth:`forward` and the
   first applied in :meth:`inverse`.

   :param bijections: Ordered list of bijections stored in noise→data (forward) order.
   :type bijections: list of Bijection

.. py:class:: RQSpline(num_bins = 8, range_bound = 5.0, min_bin_width = 0.001, min_bin_height = 0.001, min_derivative = 0.001)

   
   Elementwise monotonic rational-quadratic spline on ``[-B, B]``.

   Linear (identity) tails outside the spline interval.  The mapping is
   parameterised per dimension; with zero-initialised parameters the spline
   reduces to the identity, so the flow warm-starts as a standard normal
   (same warm-start contract as :class:`Affine`).

   The parameter layout per dimension is
   ``[widths(K), heights(K), inner_derivatives(K-1)]`` of total length
   ``3K - 1``.  Reference: Durkan et al. 2019
   (https://arxiv.org/abs/1906.04032).

   :param num_bins: Number of spline bins ``K``.  Default is 8.
   :type num_bins: int, optional
   :param range_bound: Half-width ``B`` of the spline interval ``[-B, B]``.  Default is 5.0.
   :type range_bound: float, optional
   :param min_bin_width: Minimum fractional bin width after softmax normalisation.
                         Default is 1e-3.
   :type min_bin_width: float, optional
   :param min_bin_height: Minimum fractional bin height after softmax normalisation.
                          Default is 1e-3.
   :type min_bin_height: float, optional
   :param min_derivative: Minimum knot derivative value.  Default is 1e-3.
   :type min_derivative: float, optional

.. py:class:: Standardize(dim)

   Bases: :py:obj:`gensbi.normalizing_flows.bijections.base.Bijection`


   
   Fixed affine standardization using non-trainable mean and std buffers.

   Buffers default to identity (mean 0, std 1) and can be updated in place
   via :meth:`set_stats`.  They are stored as
   :class:`~gensbi.normalizing_flows.bijections.base.Mask` variables so
   that optimizers and EMA utilities skip them.

   :param dim: Dimension of the data vector (length of mean and std buffers).
   :type dim: int
