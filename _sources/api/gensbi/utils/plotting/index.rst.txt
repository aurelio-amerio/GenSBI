gensbi.utils.plotting
=====================

.. py:module:: gensbi.utils.plotting

.. autoapi-nested-parse::

   Plotting utilities for GenSBI.

   This module provides visualization functions for generative models, including
   trajectory plots, marginal distributions, and 2D contour plots. Supports both
   seaborn and corner-based plotting styles.

.. py:function:: plot_marginals(data, backend='corner', plot_levels=None, labels=None, gridsize=15, hexbin_kwargs=None, histplot_kwargs=None, range=None, true_param=None, **kwargs)

   
   Plot marginal distributions of multidimensional data using either the 'corner' or 'seaborn' backend.

   :param data: The data to plot. Each row is a sample, each column a parameter.
   :type data: array-like, shape (n_samples, n_dim)
   :param backend: Which plotting backend to use. Options:
                   - 'corner': Use the corner.py package for a classic corner plot.
                   - 'seaborn': Use seaborn's jointplot (2D) or custom grid (ND) for marginals.
                   The seaborn backend is slower, but will produce smoother plots with KDE contours.
   :type backend: str, default="corner"
   :param plot_levels: If True and using seaborn, plot 1- and 2-sigma KDE contours on off-diagonal plots. When using 'corner', levels are automatically computed.
   :type plot_levels: bool, default=True
   :param labels: Axis labels for each parameter. If None, uses LaTeX-style $     heta_i$.
   :type labels: list of str or None, default=None
   :param gridsize: Number of bins for hexbin/histogram (seaborn) or for corner plot.
   :type gridsize: int, default=15
   :param hexbin_kwargs: Additional keyword arguments for hexbin plots (seaborn backend only).
   :type hexbin_kwargs: dict, default=None
   :param histplot_kwargs: Additional keyword arguments for histogram plots (seaborn backend only).
   :type histplot_kwargs: dict, default=None
   :param range: Axis limits for each parameter, e.g. [(xmin, xmax), (ymin, ymax), ...].
   :type range: tuple or list of tuples or None, default=None
   :param true_param: Ground truth parameter values to mark on the plots.
   :type true_param: array-like, shape (n_dim,), default=None
   :param \*\*kwargs: Additional keyword arguments passed to the underlying plotting functions.

   :returns: **fig, axes** -- The figure and axes containing the plot.
   :rtype: matplotlib Figure and Axes objects

   :raises ValueError: If an unknown backend is specified.

   .. rubric:: Notes

   - For 'corner', the function uses the corner.py package and supports labels, gridsize, range, and true_param.
   - For 'seaborn', 2D data uses jointplot, higher dimensions use a custom grid of hexbin and histogram plots.
