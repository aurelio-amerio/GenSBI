.. py:class:: PosteriorWrapper(pipeline, *args, rngs, theta_shape=None, x_shape=None, **kwargs)

   
   Wrap a GenSBI pipeline into a distribution compatible with `sbi`.

   :param pipeline:
   :type pipeline: An instance of a Pipeline from GenSBI.
   :param rngs:
   :type rngs: A nnx.Rngs instance for random number generation.
   :param theta_shape:
   :type theta_shape: Optional shape of the parameters (theta) to be sampled.
   :param x_shape:
   :type x_shape: Optional shape of the observations (x) to condition on.
   :param \*args:
   :type \*args: Additional arguments to be passed to the pipeline during sampling.
