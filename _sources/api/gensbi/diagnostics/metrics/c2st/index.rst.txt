.. py:function:: c2st(X, Y, seed = 1, n_folds = 5, metric = 'accuracy', classifier = 'rf', classifier_kwargs = None, z_score = True, noise_scale = None, verbosity = 0)

   
   Compute classifier-based two-sample test accuracy between X and Y.

   This method uses a classifier to distinguish between two sets of samples.
   If the returned accuracy is 0.5, X and Y are considered to be from the same generating distribution.
   If the accuracy is close to 1, X and Y are considered to be from different distributions.

   Training of the classifier is performed with N-fold cross-validation using scikit-learn.
   By default, a `RandomForestClassifier` is used (``classifier='rf'``).
   Alternatively, a multi-layer perceptron is available (``classifier='mlp'``).

   Both sets of samples are normalized (z-scored) using the mean and standard deviation of X,
   unless ``z_score=False``. If features in X are close to constant, the standard deviation
   is set to 1 to avoid division by zero.

   :param X: Samples from one distribution. Shape: (n_samples, n_features).
   :type X: jax.Array
   :param Y: Samples from another distribution. Shape: (n_samples, n_features).
   :type Y: jax.Array
   :param seed: Seed for the sklearn classifier and the KFold cross-validation. Default is 1.
   :type seed: int, optional
   :param n_folds: Number of folds to use for cross-validation. Default is 5.
   :type n_folds: int, optional
   :param metric: Scikit-learn metric to use for scoring. Default is 'accuracy'.
   :type metric: str, optional
   :param classifier: Classification architecture to use. 'rf' for RandomForestClassifier, 'mlp' for MLPClassifier, or a scikit-learn compatible classifier. Default is 'rf'.
   :type classifier: str or Callable, optional
   :param classifier_kwargs: Additional keyword arguments for the classifier.
   :type classifier_kwargs: dict, optional
   :param z_score: Whether to z-score X and Y using the mean and std of X. Default is True.
   :type z_score: bool, optional
   :param noise_scale: If provided, adds Gaussian noise with standard deviation ``noise_scale`` to X and Y.
   :type noise_scale: float, optional
   :param verbosity: Controls the verbosity of scikit-learn's cross_val_score. Default is 0.
   :type verbosity: int, optional

   :returns: Mean accuracy score over the test sets from cross-validation.
   :rtype: float

   .. rubric:: Examples

   >>> c2st(X, Y)
   0.519  # X and Y likely come from the same distribution
   >>> c2st(P, Q)
   0.998  # P and Q likely come from different distributions

   [1] http://arxiv.org/abs/1610.06545

   [3] https://scikit-learn.org/stable/modules/cross_validation.html
   [4] https://github.com/psteinb/c2st/
