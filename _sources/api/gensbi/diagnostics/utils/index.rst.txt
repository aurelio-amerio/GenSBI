.. py:function:: jefferys_interval(k, n, z=1)

   
   Compute Jeffrey's interval for a binomial proportion.

   Uses the Beta distribution with Jeffrey's prior (Beta(0.5, 0.5)).

   :param k: Number of successes.
   :type k: array_like
   :param n: Total number of trials.
   :type n: int or array_like
   :param z: Z-score controlling the interval width (default is 1, i.e. ~68% CI).
   :type z: float, optional

   :returns: * **lower** (*np.ndarray*) -- Lower bounds of the interval.
             * **upper** (*np.ndarray*) -- Upper bounds of the interval.
