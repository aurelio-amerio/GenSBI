.. autoapi-nested-parse::

   TarFlow: transformer autoregressive normalizing flow.

   Adapted from apple/ml-tarflow (TarFlow) and apple/ml-starflow (STARFlow);
   see models/tarflow/LICENSE.apple and LICENSE.starflow.

   Self-contained ``(B, T, F)`` density model (absorbs the former
   ``TransformerFlow`` container and the ``make_tarflow`` factory). Head sizing
   follows the Flux1 convention: specify ``head_dim`` and ``num_heads``; total
   width ``channels = head_dim * num_heads`` is derived.

.. py:class:: TarFlow(params)

   Bases: :py:obj:`flax.nnx.Module`


   
   Transformer autoregressive normalizing flow density model.

   Stacks :class:`~gensbi.models.tarflow.blocks.MetaBlock` bijections with
   alternating token permutations on top of a tokenizer and an isotropic
   Gaussian base distribution. Supports both vector and image data, with
   optional input standardization.

   :param params: Architecture and initialization parameters.
   :type params: TarFlowParams

   .. py:method:: log_prob(x, cond = None)

      
      Compute the log-probability of data under the model.

      Applies standardization, tokenizes the input, then runs each
      :class:`~gensbi.models.tarflow.blocks.MetaBlock`'s
      :meth:`~gensbi.models.tarflow.blocks.MetaBlock.inverse` transform
      (data→noise direction), accumulating the log-absolute-determinant
      terms, and finally evaluates the base Gaussian log-probability.

      :param x: Data samples of shape ``(B, *example_shape)`` or a single
                unbatched sample that will be promoted to a batch of one.
      :type x: Array
      :param cond: Conditioning batch of shape ``(B, cond_dim)`` for
                   ``cond_channels == 1``, or ``(B, cond_dim, C_cond)`` for
                   ``cond_channels > 1`` (flattened internally by the conditioner).
                   Pass ``None`` for an unconditional model.
      :type cond: Array or None, optional

      :returns: Log-probabilities of shape ``(B,)``.
      :rtype: Array

   .. py:method:: sample(key, cond = None, nsamples = None)

      
      Draw samples from the model.

      Samples noise from ``N(0, I)``, then applies each
      :class:`~gensbi.models.tarflow.blocks.MetaBlock`'s
      :meth:`~gensbi.models.tarflow.blocks.MetaBlock.forward` transform
      (noise→data direction) in reverse block order, detokenizes the
      result, and applies the inverse standardization.

      :param key: Random key for noise sampling.
      :type key: jax.random.PRNGKey
      :param cond: Conditioning batch of shape ``(nsamples, cond_dim)`` for
                   ``cond_channels == 1``, or ``(nsamples, cond_dim, C_cond)`` for
                   ``cond_channels > 1`` (flattened internally by the conditioner).
                   If provided, ``nsamples`` is inferred from ``cond.shape[0]``.
      :type cond: Array or None, optional
      :param nsamples: Number of samples to draw. Required when ``cond`` is ``None``.
      :type nsamples: int or None, optional

      :returns: Samples of shape ``(B, *example_shape)``.
      :rtype: Array

   .. py:method:: set_standardization(mean, std)

      
      Set the mean and standard deviation for input standardization.

      Accepts shapes ``(dim,)`` (broadcast to ``(dim, 1)``), ``(dim, 1)``,
      ``(C,)`` (per-channel broadcast), or a scalar broadcastable to
      ``example_shape``.

      :param mean: Mean broadcastable to ``example_shape``.
      :type mean: Array
      :param std: Standard deviation broadcastable to ``example_shape``.
      :type std: Array

      :rtype: None

      :raises ValueError: If the model was built with ``standardize=False``.

.. py:class:: TarFlowParams

   
   Architecture parameters for :class:`TarFlow`.

   ``modeled`` selects the tokenizer (``"vector"`` or ``"image"``); ``cond``
   selects the conditioner (``"bias"``, ``"vector"``, or
   ``"image"``). Head sizing follows the Flux1 convention: specify
   ``head_dim`` and ``num_heads``; total width
   ``channels = head_dim * num_heads`` is derived in ``__post_init__``.

   :param rngs: Flax RNG container passed to all sub-modules during construction.
   :type rngs: nnx.Rngs
   :param dim: Feature dimension of each input vector. Required when
               ``modeled="vector"``. Default is ``None``.
   :type dim: int or None, optional
   :param cond_dim: Dimensionality of the conditioning vector. Set to ``0`` for an
                    unconditional model. Default is ``0``.
   :type cond_dim: int, optional
   :param modeled: Tokenizer type: ``"vector"`` (1-D data) or ``"image"`` (spatial data).
                   Default is ``"vector"``.
   :type modeled: str, optional
   :param img_size: Spatial size (height = width) of the modeled image. Required when
                    ``modeled="image"``. Default is ``None``.
   :type img_size: int or None, optional
   :param patch_size: Patch size for the image tokenizer. Required when
                      ``modeled="image"``. Default is ``None``.
   :type patch_size: int or None, optional
   :param img_channels: Number of channels in the modeled image. Default is ``1``.
   :type img_channels: int, optional
   :param cond: Conditioning strategy: ``"bias"`` (per-token additive bias via
                :class:`~gensbi.models.tarflow.conditioners.AdditiveBiasConditioner`),
                ``"vector"`` (one condition token per modeled coordinate via
                :class:`~gensbi.models.tarflow.conditioners.VectorConditioner`),
                or ``"image"`` (prefix tokens from an image via
                :class:`~gensbi.models.tarflow.conditioners.ImageConditioner`).
                Default is ``"bias"``.
   :type cond: str, optional
   :param cond_img_size: Spatial size of the conditioning image. Required when
                         ``cond="image"``. Default is ``None``.
   :type cond_img_size: int or None, optional
   :param cond_patch_size: Patch size for the image conditioning tokenizer. Required when
                           ``cond="image"``. Default is ``None``.
   :type cond_patch_size: int or None, optional
   :param cond_channels: Number of channels in the conditioning image. Default is ``1``.
   :type cond_channels: int, optional
   :param head_dim: Dimension per attention head. Default is ``16``.
   :type head_dim: int, optional
   :param num_heads: Number of attention heads per block. Default is ``4``.
   :type num_heads: int, optional
   :param num_blocks: Number of :class:`~gensbi.models.tarflow.blocks.MetaBlock` layers.
                      Default is ``8``.
   :type num_blocks: int, optional
   :param layers_per_block: Number of :class:`~gensbi.models.tarflow.blocks.AttentionBlock`
                            layers inside each :class:`~gensbi.models.tarflow.blocks.MetaBlock`.
                            Default is ``2``.
   :type layers_per_block: int, optional
   :param block_size: Token grouping factor for the vector tokenizer. Default is ``1``.
   :type block_size: int, optional
   :param permutation: Token permutation strategy per block: ``"flip"`` (alternate
                       forward/reverse order) or ``"random"`` (independently sampled per
                       block). Default is ``"flip"``.
   :type permutation: str, optional
   :param standardize: If ``True`` (default), apply mean/std standardization to inputs and
                       outputs. Enables :meth:`TarFlow.set_standardization`.
   :type standardize: bool, optional
   :param zero_init: If ``True`` (default), initialize ``proj_out`` weights to zero so
                     each :class:`~gensbi.models.tarflow.blocks.MetaBlock` starts as the
                     identity map.
   :type zero_init: bool, optional
   :param use_softplus: If ``True`` (default), use softplus for the affine scale (numerically
                        stable, bounded tail). If ``False``, use ``exp`` (legacy behavior).
   :type use_softplus: bool, optional
   :param soft_clip: Soft-clip magnitude applied via ``tanh`` to raw network outputs before
                     splitting into ``(a, b)``. Default is ``4.0``.
   :type soft_clip: float, optional
   :param use_rope: If ``True``, replace the learned per-token ``pos_embed`` for the
                    modeled image tokens with 2D rotary position embeddings
                    (:class:`~gensbi.models.tarflow.pe.VisionRotaryEmbedding`). Prefix
                    (condition) tokens keep their learned embeddings and sit at the
                    identity rotation (zero angles). Requires ``modeled="image"`` and
                    ``head_dim`` divisible by ``4``. ``head_dim >= 32`` is recommended
                    for image data (more rotary frequencies per axis) but not enforced.
                    Default is ``False``.
   :type use_rope: bool, optional
   :param rope_theta: Frequency base for the rotary embedding. Only used when
                      ``use_rope=True``. Default is ``10000``.
   :type rope_theta: int, optional
   :param param_dtype: Dtype for all stored (master) kernel/bias/embedding parameters
                       across the tokenizer, conditioner, and transformer blocks. Default
                       is ``float32``.
   :type param_dtype: DTypeLike, optional
   :param dtype: Compute dtype knob threaded through the conditioners and
                 :class:`~gensbi.models.tarflow.blocks.MetaBlock`/
                 :class:`~gensbi.models.tarflow.blocks.AttentionBlock` layers.
                 Default is ``float32``, matching ``param_dtype``, so with default
                 arguments this is a bit-identical no-op cast. Hard-fp32 regardless
                 of this knob: the softplus/soft_clip affine-scale path in
                 ``MetaBlock._affine``, log-det accumulation, the ``mean``/``std``
                 standardization buffers, and the KV-cache buffers used during
                 sampling.
   :type dtype: DTypeLike, optional
