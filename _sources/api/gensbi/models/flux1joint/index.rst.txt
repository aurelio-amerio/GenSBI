   Flux1Joint Model in GenSBI
   -------------------------

   This package provides the Flux1Joint transformer-based model and related loss functions for simulation-based inference. The architecture is derived from the following foundational work:

   * M. Gloeckler et al. "All-in-one simulation-based inference." `arXiv:2404.09636 <https://arxiv.org/abs/2404.09636>`_
   * `mackelab/simformer <https://github.com/mackelab/simformer>`_

.. py:class:: Flux1JointParams

   
   Parameters for the Flux1Joint model.

   GenSBI uses the tensor convention `(batch, dim, channels)`.

   For joint density estimation, the model consumes a *single* sequence `obs` that
   mixes all variables you want to model jointly. In this case:

   - `dim_joint` is the number of tokens in that joint sequence.
   - `in_channels` is the number of channels/features per token.

   In many SBI-style problems you will still use `in_channels = 1` (one scalar per token),
   but for some datasets a token may carry multiple features.

   :param in_channels: Number of channels/features per token.
   :type in_channels: int
   :param vec_in_dim: Dimension of the vector input, if applicable.
   :type vec_in_dim: Union[int, None]
   :param mlp_ratio: Ratio for the MLP layers.
   :type mlp_ratio: float
   :param num_heads: Number of attention heads.
   :type num_heads: int
   :param depth_single_blocks: Number of single stream blocks.
   :type depth_single_blocks: int
   :param val_emb_dim: Number of features per head used to embed the data.
   :type val_emb_dim: int
   :param cond_emb_dim: Number of features per head used to encode the condition mask, which determines the features on which we are conditioning.
   :type cond_emb_dim: int
   :param id_emb_dim: Number of features per head used to encode the token ids.
   :type id_emb_dim: int
   :param qkv_bias: Whether to use bias in QKV layers.
   :type qkv_bias: bool
   :param rngs: Random number generators for initialization.
   :type rngs: nnx.Rngs
   :param dim_joint: Number of tokens in the joint sequence.
   :type dim_joint: int
   :param id_merge_mode: Strategy for combining embeddings ("sum" or "concat").
   :type id_merge_mode: str
   :param id_embedding_strategy: Kind of ID embedding. Currently only "absolute" is supported for Flux1Joint.
   :type id_embedding_strategy: str
   :param guidance_embed: Whether to use guidance embedding.
   :type guidance_embed: bool
   :param param_dtype: Data type for master-weight storage (parameters). Defaults to jnp.float32.
   :type param_dtype: DTypeLike
   :param dtype: Compute/matmul dtype used by the compute layers. Defaults to jnp.bfloat16.
   :type dtype: DTypeLike
