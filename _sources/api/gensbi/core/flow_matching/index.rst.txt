.. py:class:: FlowMatchingMethod(prior=None)

   Bases: :py:obj:`gensbi.core.generative_method.GenerativeMethod`


   
   Flow matching strategy using affine probability paths.

   Uses the conditional optimal-transport scheduler and an ODE or SDE
   solver for sampling.

   :param prior: Source distribution. Must implement ``sample(key, shape)`` and
                 ``log_prob(x)``. If you need log-probability evaluation (via
                 ``build_log_prob_fn``), the prior **must** be a proper numpyro
                 distribution. Defaults to ``StandardNormalPrior`` (≡ N(0, I)).
   :type prior: numpyro.distributions.Distribution, optional

   .. rubric:: Examples

   >>> method = FlowMatchingMethod()
   >>> path = method.build_path(config={})
   >>> loss = method.build_loss(path)

   Using a custom numpyro prior (x has shape ``(batch, dim_obs, ch_obs)``):

   >>> import numpyro.distributions as dist
   >>> dim_obs, ch_obs = 3, 1
   >>> prior = dist.Independent(
   ...     dist.Normal(loc=jnp.zeros((dim_obs, ch_obs)), scale=jnp.ones((dim_obs, ch_obs))),
   ...     reinterpreted_batch_ndims=2,
   ... )
   >>> method = FlowMatchingMethod(prior=prior)

   .. py:method:: build_log_prob_fn(model_wrapped, path, model_extras, step_size=0.01, method='Dopri5', atol=1e-05, rtol=1e-05, time_grid=None, solver=None, exact_divergence=True, **kwargs)

      
      Build a log-probability closure for flow matching.

      Uses the continuous change-of-variables formula via ``ODESolver``.
      Only works with ODE solvers (not SDE solvers).

      :param model_wrapped: The wrapped velocity field model.
      :param path: The probability path.
      :param model_extras: Mode-specific extras (``cond``, ``obs_ids``, etc.).
      :type model_extras: dict
      :param step_size: Step size for fixed-step solvers. Default is 0.01.
      :type step_size: float, optional
      :param method: Integration method. Default is ``"Dopri5"``.
      :type method: str or diffrax solver, optional
      :param atol: Absolute tolerance for adaptive solvers.
      :type atol: float, optional
      :param rtol: Relative tolerance for adaptive solvers.
      :type rtol: float, optional
      :param time_grid: Time grid. Defaults to ``[1.0, 0.0]``.
      :type time_grid: list, optional
      :param solver: ``(SolverClass, kwargs)``. Must be an ODE solver.
      :type solver: tuple of (type, dict), optional
      :param exact_divergence: If ``True`` (default), compute exact divergence via full
                               Jacobian. If ``False``, use the Hutchinson estimator (requires
                               a PRNG ``key`` at call time).
      :type exact_divergence: bool, optional

      :returns: **log_prob_fn** -- ``(x_1, model_extras, *, key=None) -> log_prob``.
      :rtype: Callable

      :raises NotImplementedError: If a non-ODE solver is specified.

   .. py:method:: build_sampler_fn(model_wrapped, path, model_extras, step_size=0.01, time_grid=None, solver=None, **kwargs)

      
      Build a sampler closure for flow matching.

      Supports ODE solvers (deterministic) and SDE solvers (stochastic;
      ``ZeroEndsSolver``, ``NonSingularSolver``). When an SDE solver is
      used, the sampler function accepts and splits an extra random key.

      :param model_wrapped: The wrapped velocity field model.
      :param path: The probability path.
      :param model_extras: Mode-specific extras (``cond``, ``obs_ids``, ``cond_ids``, etc.).
      :type model_extras: dict
      :param step_size: Step size for fixed-step solvers. Default is 0.01.
      :type step_size: float, optional
      :param time_grid: Time grid for integration. If ``None``, uses ``[0, 1]``.
      :type time_grid: Array, optional
      :param solver: ``(SolverClass, kwargs)``. Defaults to ``(ODESolver, {})``.
      :type solver: tuple of (type, dict), optional

      :returns: **sampler_fn** -- A function ``(key, x_init) -> samples``.
      :rtype: Callable

.. py:class:: StandardNormalPrior

   
   Default prior: standard normal distribution with ``log_prob`` support.

   Wraps ``jax.random.normal`` for sampling and uses
   ``numpyro.distributions.Independent(Normal(...))`` for ``log_prob``.
   The distribution is lazily constructed on the first ``log_prob`` call
   to match the shape of the input.
