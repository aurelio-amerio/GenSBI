gensbi.experimental
===================

.. py:module:: gensbi.experimental

.. autoapi-nested-parse::

   
   Experimental module for GenSBI.

   This module contains experimental features and models that are not yet part of the stable API.

   .. note::

      This module is subject to change and may not be backward compatible in future releases.
      Use with caution and refer to the documentation for the latest updates.

      Experimental features include:
      - Variational Autoencoders (VAEs) and pipelines
      - Latent generative pipeline implementations
