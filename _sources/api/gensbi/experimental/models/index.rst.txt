.. py:class:: AutoEncoderParams

   
   Configuration parameters for the AutoEncoder models.

   .. attribute:: resolution

      The input feature dimension (length for 1D, height/width for 2D).

      :type: int

   .. attribute:: in_channels

      Number of input channels (e.g., 1 for scalar features, >1 for multi-channel).

      :type: int

   .. attribute:: ch

      Base number of channels for the first convolutional layer.

      :type: int

   .. attribute:: out_ch

      Number of output channels produced by the decoder (matches input channels for reconstruction).

      :type: int

   .. attribute:: ch_mult

      Multipliers for the number of channels at each resolution level (controls model width/depth).

      :type: list[int]

   .. attribute:: num_res_blocks

      Number of residual blocks per resolution level.

      :type: int

   .. attribute:: z_channels

      Number of latent channels in the bottleneck (size of encoded representation).

      :type: int

   .. attribute:: scale_factor

      Scaling factor applied to the latent representation (for normalization or data scaling).

      :type: float

   .. attribute:: shift_factor

      Shift factor applied to the latent representation (for normalization or data centering).

      :type: float

   .. attribute:: rngs

      Random number generators for parameter initialization and stochastic layers.

      :type: nnx.Rngs

   .. attribute:: param_dtype

      Data type for model parameters (e.g., jnp.float32, jnp.bfloat16).

      :type: DTypeLike

.. py:class:: Embedded1DModel(vae, sbi_model)

   Bases: :py:obj:`flax.nnx.Module`


   
   Wraps a VAE encoder and a Flux1 SBI model for 1D sequence conditioning.

   Encodes raw 1D conditioning sequences into latent space via the VAE and
   forwards everything to the underlying SBI model. Unlike ``Embedded2DModel``,
   no patchification step is applied after encoding.

   :param vae: Variational autoencoder used to encode conditioning sequences into latents.
   :type vae: AutoEncoder1D
   :param sbi_model: Simulation-based inference model that receives the encoded conditioning.
   :type sbi_model: Flux1

      :type t: Array
      :param obs: Observation tokens (noisy samples) passed directly to the SBI model.
      :type obs: Array
      :param obs_ids: Positional IDs for the observation tokens.
      :type obs_ids: Array
      :param cond: Raw 1D conditioning sequences to be encoded by the VAE, shape
                   ``(batch, L, C)``.
      :type cond: Array

.. py:class:: FieldDiT(params)

   Bases: :py:obj:`flax.nnx.Module`


   
   Conditional flow-matching network for 2D fields (pixel space).

   Forward: ``(t, obs=field, cond) -> velocity field`` of the same shape. The
   conv encoder is modulated by time only (or by the full ``vec`` when
   ``cond_modulates_encoder=True``); the decoder and the MMDiT core are
   modulated by ``vec = time (+ cond summary if flagged-C) (+ guidance)``. The
   meeting-grid rope2d obs ids and absolute cond ids are built internally.

.. py:class:: FieldDiTParams

   
   Configuration for :class:`FieldDiT` (mirrors the style of ``Flux1Params``).

   The meeting-grid token count is **derived** from ``field_shape``,
   ``encoder_widths`` (depth) and ``patch_size`` — it is not prescribed:
   ``tokens = (H / (2**D * p)) * (W / (2**D * p))`` with ``D = len(encoder_widths) - 1``.

   Note: ``rngs`` is a live ``nnx.Rngs`` stream (mirrors ``Flux1Params``).
   Constructing two models from the *same* params object yields *different*
   weights, because the stream advances; build a fresh ``FieldDiTParams``
   (or a fresh ``nnx.Rngs(seed)``) per model for reproducibility.

.. py:class:: PixelDiT(params)

   Bases: :py:obj:`flax.nnx.Module`


   
   Dual-level pixel-space DiT for conditional flow matching on 2D fields.

   Forward: ``(t, obs=field, cond) -> velocity field`` of the same shape.
   Patch-level MMDiT blocks attend over patch tokens jointly with cond tokens,
   producing per-patch conditioning ``s_cond``; pixel-level PiT blocks then
   refine every pixel inside each patch under that conditioning.
