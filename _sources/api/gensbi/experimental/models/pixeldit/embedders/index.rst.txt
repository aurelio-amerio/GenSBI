gensbi.experimental.models.pixeldit.embedders
=============================================

.. py:module:: gensbi.experimental.models.pixeldit.embedders

.. autoapi-nested-parse::

   Token embedders for the PixelDiT port.

   Faithful port of ``reference/PixelDiT/pixdit_core/pixeldit_c2i.py`` embedders
   plus the cond-token embedder from ``pixeldit_t2i.py``.  Operates channel-last
   ``(B, H, W, C)`` throughout.

   Bases: :py:obj:`flax.nnx.Module`


   
   Condition token embedder: linear → RMSNorm → add id embedding.

   Faithful port of the t2i cond pipeline
   (``y_embedder`` + ``y_pos_embedding``, pixeldit_t2i.py:179-180, 267-268).

   :param cond_in_channels: Dimension of each condition token ``D_c``.
   :param hidden_size: Output embedding dimension ``D``.
   :param n_tokens: Number of condition tokens ``K`` (used to build the id embedding table).
   :param id_embedding: How to embed token positions: ``"absolute"`` (learned), ``"pos1d"``
                        (sinusoidal 1D), or ``"none"`` (no positional information added).

.. py:class:: PixelTokenEmbedder(in_channels, pixel_hidden_size, field_shape, patch_size, *, use_abs_pos = True, rngs, param_dtype = jnp.bfloat16)

   Bases: :py:obj:`flax.nnx.Module`


   
   Per-pixel projection + optional sincos abs-pos + patch grouping.

   Faithful port of ``PixelTokenEmbedder.forward`` (pixeldit_c2i.py:93-111).
   Operates channel-last: input ``(B, H, W, C)``, output ``(B·L, p², D_pix)``.

   :param in_channels: Number of input channels ``C``.
   :param pixel_hidden_size: Per-pixel hidden dimension ``D_pix``.
   :param field_shape: ``(H, W)`` — fixed spatial resolution; the sincos table is precomputed
                       and stored as a non-trainable :class:`Buffer`.
   :param patch_size: Patch size ``p``.
   :param use_abs_pos: If ``True`` (default), add the sincos 2D positional embedding.
