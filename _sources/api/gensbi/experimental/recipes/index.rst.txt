   Bases: :py:obj:`gensbi.recipes.pipeline.AbstractPipeline`


   
   Diffusion pipeline for training and using a Conditional model for simulation-based inference.

   :param train_dataset: Training dataset.
   :type train_dataset: grain dataset or iterator over batches
   :param val_dataset: Validation dataset.
   :type val_dataset: grain dataset or iterator over batches
   :param dim_obs: Dimension of the parameter space.
   :type dim_obs: int
   :param dim_cond: Dimension of the observation space.
   :type dim_cond: int
   :param params: Parameters for the Conditional model. If None, default parameters are used.
   :type params: ConditionalParams, optional
   :param vae_obs: VAE module for the observation input. If None, no encoding is applied.
   :type vae_obs: nnx.Module, optional
   :param vae_cond: VAE module for the conditional input. If None, no encoding is applied.
   :type vae_cond: nnx.Module, optional
   :param training_config: Configuration for training. If None, default configuration is used.
   :type training_config: dict, optional
