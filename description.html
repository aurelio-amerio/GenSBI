GenSBI is a JAX-based library for simulation-based inference (SBI) using state-of-the-art generative methods, currently centred on optimal-transport flow matching and diffusion models. It offers a flexible, high-performance toolkit for inference problems where the likelihood is intractable, featuring transformer-based architectures (SimFormer, Flux1, and Flux1Join), built-in posterior calibration diagnostics (SBC, TARP, L-C2ST), and a high-level recipes API. Built on JAX and Flax NNX, it runs seamlessly on CPU, GPU, and TPU.

Installation

pip install gensbi

# with GPU (CUDA 12) support:
pip install gensbi[cuda12]

For other installation options (uv, TPU, CUDA 13) and a full getting-started guide, see the documentation.

Documentation: https://gensbi.com
